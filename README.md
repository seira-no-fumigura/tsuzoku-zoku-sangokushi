## 作品について

『続三国志』（三国志のあとの晋の事）の江戸時代の和訳。中村昂然の『通俗続三国志』で、巻之一から巻之三十七までを収める。明治 45 年（1912 年）に早稲田大学出版部が『通俗二十一史』の第 6 巻として出したもの。OCR の柱から付けた見出しが付く（柱が読めなかった巻は見出しに立てていない）。巻頭の例言・解題・支那歴代沿革略系・年表（早稲田大学編輯部）は入れていない。

国立国会図書館デジタルコレクションの「インターネット公開（保護期間満了）」の資料です。

## 本文の作り方

国立国会図書館デジタルコレクション（インターネット公開）の全文テキスト（OCR）をそのまま収めた。1 段落が底本の 1 コマ（見開き）。校正はしていないので、振り仮名や柱の混じり、読み違いが残る。
